Value counts

Count how often each distinct value appears in a column, sorted from most to least common.

dept_counts = df["dept"].value_counts()

Shares instead of counts, with missing values counted too:

dept_shares = df["dept"].value_counts(normalize=True, dropna=False)

Counts of each combination of several columns:

pair_counts = df.value_counts(["dept", "city"])
  • NaN is left out by default; dropna=False includes it.
  • sort=False keeps first-seen order; .sort_index() orders by value instead of count.
  • df.groupby("dept").size() gives the same counts, sorted by dept.
  • df["dept"].nunique() is the number of distinct values.

groupby().count() vs value_counts()

per_dept = df.groupby("dept")["salary"].count()   # non-null salaries in each dept, sorted by dept
dept_counts = df["dept"].value_counts()            # rows per dept, most common first

Dates and times

Parse first. The .dt accessor only works on datetime64 columns, so convert strings before anything else.

df["date"] = pd.to_datetime(df["date"])                      # "2024-03-15" → Timestamp
df["date"] = pd.to_datetime(df["date"], format="%d/%m/%Y")   # explicit format: faster, no guessing
df["date"] = pd.to_datetime(df["date"], errors="coerce")     # unparseable values → NaT
df = pd.read_csv("sales.csv", parse_dates=["date"])          # parse while loading

Extract parts with .dt:

df["year"] = df["date"].dt.year
df["month"] = df["date"].dt.month
df["month_name"] = df["date"].dt.month_name()
df["weekday"] = df["date"].dt.day_name()
df["is_weekend"] = df["date"].dt.dayofweek >= 5

Date arithmetic: subtracting dates gives a Timedelta.

df["days_to_ship"] = (df["shipped"] - df["ordered"]).dt.days
df["due"] = df["ordered"] + pd.Timedelta(days=7)
df["next_month"] = df["ordered"] + pd.DateOffset(months=1)   # calendar-aware: Jan 31 → Feb 29
df["age_days"] = (pd.Timestamp("today") - df["joined"]).dt.days

Filter by date: compare against date strings.

recent = df[df["date"] >= "2024-01-01"]
q1 = df[df["date"].between("2024-01-01", "2024-03-31")]
march = df[(df["date"].dt.year == 2024) & (df["date"].dt.month == 3)]

Totals per month:

monthly = df.resample("ME", on="date")["revenue"].sum()                 # one row per calendar month
monthly = df.groupby(df["date"].dt.to_period("M"))["revenue"].sum()    # same, labelled 2024-03
by_month = df.groupby(df["date"].dt.month)["revenue"].sum()            # 1–12, all years pooled
  • "ME" means month-end in pandas ≥ 2.2; older versions use "M". Also "D", "W", "QE", "YE".
  • Grouping by .dt.month pools every year together; use to_period("M") or resample to keep years apart.
  • With df.set_index("date"), partial strings select ranges: df.loc["2024-03"] or df.loc["2024-01":"2024-06"] (sort the index first).
  • Time zones: .dt.tz_localize("UTC") attaches one; .dt.tz_convert("Asia/Kolkata") converts.

Map

Translate each value of a column through a dictionary (or a function).

seg_map = {"C": "Consumer", "B": "Business"}
df["segment_name"] = df["segment"].map(seg_map)

With a function, applied to each value:

df["name_length"] = df["name"].map(len)
  • Values missing from the dictionary become NaN.
  • replace(seg_map) swaps only the values it finds and leaves the rest unchanged.
  • map works on a Series. For element-wise work on a whole DataFrame, use df.map(func) (pandas ≥ 2.1, formerly applymap).

Pivot table

Reshape long rows into a grid: one row per index value, one column per columns value, cells filled by aggfunc over values.

pivot = df.pivot_table(
    index="region",      # row labels
    columns="product",   # column labels
    values="revenue",    # what to aggregate
    aggfunc="sum",       # default is "mean"
    fill_value=0,        # empty cells become 0 instead of NaN
)

The same grid with groupby: aggregate, then move the inner key into columns.

totals = df.groupby(["region", "product"])["revenue"].sum()
pivot = totals.unstack(fill_value=0)
  • aggfunc defaults to "mean", so ask for "sum" when you want totals.
  • pivot_table aggregates duplicate keys; df.pivot(...) doesn't and raises an error if a key repeats.
  • margins=True adds an All row and column with grand totals.
  • The inverse, wide → long, is melt (next card).

Melt

Reshape wide → long: one row per id-and-month pair. Starting from columns id, jan, feb, mar, produce columns id, month, sales.

long = df.melt(
    id_vars="id",          # columns kept as they are
    var_name="month",      # new column holding the old column names
    value_name="sales",    # new column holding their values
)

  • Every column not in id_vars is melted; value_vars=["jan", "feb"] limits which ones.
  • Rows come out grouped by month. .sort_values(["id", "month"]) groups them by id instead.
  • The inverse, long → wide, is long.pivot(index="id", columns="month", values="sales").

Concat

Stack DataFrames with the same columns on top of each other. pd.concat takes a list.

combined = pd.concat([df1, df2], ignore_index=True)  # renumber rows 0…n-1

Place frames side by side instead, aligned on the index:

wide = pd.concat([features, labels], axis=1)
  • Without ignore_index=True, the original row labels are kept, so the result can have duplicate index values.
  • Columns missing from one frame are filled with NaN; pass join="inner" to keep only shared columns.
  • keys=["2024", "2025"] labels where each row came from, as an outer index level.
  • Concat stacks; to match rows on a key column, use merge.

Groupby: aggregation and transform

Aggregation collapses each group to one row.

avg_salary = df.groupby("dept")["salary"].mean()

Several statistics at once, with named output columns:

dept_stats = df.groupby("dept").agg(
    avg_salary=("salary", "mean"),
    max_salary=("salary", "max"),
    headcount=("name", "count"),
)

Group by several keys, keeping them as ordinary columns:

by_dept_city = df.groupby(["dept", "city"], as_index=False)["salary"].sum()

Transform returns one value per original row, aligned to the original index, so it can be assigned straight back as a column.

df["dept_avg"] = df.groupby("dept")["salary"].transform("mean")
df["salary_vs_dept"] = df["salary"] - df["dept_avg"]

Share of the department total, and rank within the department:

dept_total = df.groupby("dept")["salary"].transform("sum")
df["salary_share"] = df["salary"] / dept_total
df["dept_rank"] = df.groupby("dept")["salary"].rank(ascending=False)
  • agg → one row per group; transform → same length as df.
  • Select the column before aggregating (["salary"]) so other columns aren't aggregated too.
  • Group keys become the index after agg; as_index=False or .reset_index() turns them back into columns.
  • Missing keys are dropped from groups by default; dropna=False keeps a NaN group.

Rolling mean

A moving average over the previous n rows. Sort by date first, because the window follows row order.

daily = df.sort_values("date")
daily["sales_7d"] = daily["sales"].rolling(7).mean()  # mean of this row and the 6 before it

A time-based window uses calendar days, so gaps in the dates are handled correctly:

daily = daily.set_index("date")
daily["sales_7d"] = daily["sales"].rolling("7D").mean()

Rolling within each group, such as per store:

by_store = daily.groupby("store")["sales"]
daily["store_sales_7d"] = by_store.transform(lambda s: s.rolling(7).mean())
  • The first n − 1 results are NaN; min_periods=1 averages whatever rows exist so far.
  • center=True centres the window on each row instead of looking back.
  • Swap .mean() for .sum(), .std(), .max() and so on.
