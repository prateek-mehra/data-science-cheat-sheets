1. Notation & the quick choice
SymbolMeaningTypical use
\(y\)Ground-truth label or targetWhat should be predicted
\(p\)Predicted probability; \(z\) is a raw logitClassification
\(\hat y\)Predicted continuous valueRegression
\(N\)Number of examples or elements being averagedBatch / pixels / tokens
Quick rule: mutually exclusive classes → softmax + CCE; independent binary labels → sigmoid + BCE; continuous targets → regression loss; dense object detection → a weighted sum of classification and box-localization losses. Frameworks often compute BCE/CCE directly from logits for numerical stability.

2. Binary cross-entropy (BCE)
\(L = -\frac{1}{N} \sum \left[ y \log p + (1-y) \log(1-p) \right]\)
  • Use: binary classification or multi-label classification (one independent yes/no target per class).
  • With a logit \(z\), \(p = \sigma(z)\); prefer a numerically stable “with logits” implementation.
  • Common pitfall: do not apply sigmoid twice if the loss already expects logits.
  • For imbalance, consider positive-class weights, sampling, or focal loss; tune calibration separately.

3. Categorical cross-entropy (CCE)
\(L = -\frac{1}{N} \sum_i \sum_k y_{ik} \log p_{ik}\)
  • Use: exactly one correct class from \(K\) mutually exclusive classes.
  • \(p = \operatorname{softmax}(z)\); for one-hot labels this is \(-\log p_{\text{correct class}}\).
  • Integer class IDs are commonly accepted by sparse CCE. Use logits-based loss for stability.
  • Distinguish: BCE treats class outputs independently; CCE couples them so probabilities sum to 1.

4. Focal loss · hard examples get more attention
\(\mathrm{FL}(p_t) = -\alpha_t (1-p_t)^{\gamma} \log(p_t)\)   where \(p_t = \begin{cases} p & y = 1 \\ 1-p & \text{otherwise} \end{cases}\)
KnobEffectInterview explanation
\(\gamma \ge 0\)Down-weights easy, already-correct examples as \(p_t \to 1\).Addresses the flood of easy negatives in dense detection.
\(\alpha_t\)Balances positive and negative classes.Class weighting; it is separate from the focusing factor.
\(\gamma = 0\)Reduces to alpha-weighted cross-entropy.Check limiting cases to show you understand the formula.
Use when: extreme foreground/background imbalance, especially dense detection. It is not automatically better for ordinary balanced classification; changing loss can affect calibration.

5. Regression errors
LossFormula (per scalar error \(e = \hat y - y\))Behavior / when useful
MSE / L2\(\frac{1}{N} \sum e^2\)Strongly penalizes large errors; smooth gradients. Sensitive to outliers. Minimizer estimates the conditional mean.
MAE / L1\(\frac{1}{N} \sum |e|\)More robust to outliers; gradient magnitude is constant away from zero. Minimizer estimates the conditional median.
Huber\(\rho_\delta(e) = \begin{cases} \tfrac12 e^2 & |e| \le \delta \\ \delta(|e| - \tfrac12\delta) & \text{otherwise} \end{cases}\)Quadratic near zero, linear for large errors; robust while retaining smooth behavior near the target.
Smooth L1\(\begin{cases} \tfrac12 e^2/\beta & |e| \lt \beta \\ |e| - \tfrac12\beta & \text{otherwise} \end{cases}\)Huber-like loss used in detection and localization; framework conventions differ in the transition scale.
Log-cosh\(\operatorname{mean}(\log \cosh e)\)Quadratic for small errors and approximately linear for large errors; smooth everywhere.
Quantile / pinball\(\rho_\tau(e) = \max(\tau e, (\tau-1)e)\)Quantile regression; asymmetric penalties estimate a chosen conditional quantile \(\tau\) rather than the mean.
Interview choice: MSE if large misses should cost disproportionately; MAE if outliers should not dominate; Huber if you want a smooth compromise. Check target scaling and units before interpreting raw loss values.

6. YOLO & object-detection losses
ComponentCommon formPurpose / nuance
Box overlap\(L_{\mathrm{IoU}} = 1 - \mathrm{IoU}\)
\(\mathrm{GIoU} = \mathrm{IoU} - \frac{|C \setminus (A \cup B)|}{|C|}, \quad L = 1 - \mathrm{GIoU}\)		Optimize localization in terms of box overlap. GIoU adds a penalty for the smallest enclosing box \(C\), giving a useful signal when boxes do not overlap.
DIoU / CIoU\(\mathrm{DIoU} = \mathrm{IoU} - \frac{\rho^2(b, b^*)}{c^2}\)
\(\mathrm{CIoU} = \mathrm{DIoU} - \alpha v\)		DIoU adds center-distance penalty; CIoU also accounts for aspect-ratio mismatch. Box loss is often \(1 - \mathrm{CIoU}\).
Class / objectness\(\mathrm{BCEWithLogits}(z, y)\)Train class scores and, in heads that use it, objectness/confidence scores. Assignment and class imbalance treatment depend on the YOLO version.
Distribution Focal Loss\(\mathrm{DFL}(y) = -\left[(y_r - y)\log S_l + (y - y_l)\log S_r\right]\)Regress each box side as a distribution over neighboring distance bins; interpolation supervises the two bins \(y_l \le y \le y_r\) around target \(y\).
Total (illustrative)\(L = \lambda_{\text{box}} L_{\text{box}} + \lambda_{\text{cls}} L_{\text{cls}} + \lambda_{\text{dfl}} L_{\text{dfl}}\)Modern anchor-free YOLO families combine box, class, and often DFL terms. Weights and assignment rules vary by model/release.
YOLO26 nuanceIoU box loss + BCE class loss + normalized L1 box-distance termYOLO26 is DFL-free: the training-recipe dfl gain weights normalized L1 distances, not distribution focal loss. NMS-free is an inference path, not a loss function.
Version caveat: YOLOv1 used weighted squared-error terms; newer YOLOs use different classification, box, assignment, and auxiliary terms. Never describe one formula as the loss for every YOLO version.

7. Other high-value interview losses
LossFormulaUse
Hinge\(\max(0,\, 1 - y \cdot f(x))\), \(y \in \{-1, +1\}\)Max-margin classifiers / SVM intuition.
KL divergence\(\sum p \log \frac{p}{q}\)Distribution matching, knowledge distillation, VAEs. Direction matters; \(\mathrm{KL}(p \,\|\, q)\) is not symmetric.
Dice\(1 - \frac{2\sum py + \varepsilon}{\sum p + \sum y + \varepsilon}\)Segmentation with sparse foreground; overlap-based objective.
Triplet\(\max(0,\, d(a,p) - d(a,n) + m)\)Metric learning: anchor-positive closer than anchor-negative by margin \(m\).
InfoNCE\(-\log \frac{\exp(\mathrm{sim}(q,k^+)/\tau)}{\sum_j \exp(\mathrm{sim}(q,k_j)/\tau)}\)Contrastive representation learning; identify a positive among negatives.
Pairwise ranking\(-\log \sigma(s^+ - s^-)\)Learn relative order for search, recommendation, and ranking.

8. Common interview checks
  • Loss vs metric: loss is optimized; accuracy, F1, AP, or IoU may be monitored but are often non-differentiable.
  • Imbalance: compare class weights, resampling, focal loss, and threshold tuning.
  • Probability: BCE for independent labels; CCE for one-of-K labels.
  • Outliers: square error amplifies them; absolute / Huber-style errors are more robust.
  • Segmentation: pixel CE gives local supervision; Dice/IoU directly emphasize overlap.
  • Multi-task models: \(L_{\text{total}} = \sum_i \lambda_i L_i\); loss scales can dominate, so normalize or tune weights.
  • Numerics: use logits-based cross-entropy and stable log-sum-exp implementations.
