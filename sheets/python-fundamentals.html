Bool
  • bool is a subclass of int.

Operators
  • == checks whether values are equal.
  • is checks whether two references point to the exact same object.
  • Exponentiation groups from the right: 2 ** (3 ** 2).
  • Empty strings and lists are falsey. or returns the first truthy operand itself, not a Boolean.
  • // floors toward negative infinity.

Strings
  • str.find() returns -1 when no match is found.
  • capitalize() uppercases the first character and lowercases the remaining characters; for example, "cAT".capitalize() returns "Cat".
  • sorted(["10", "2", "1"]) sorts lexicographically.

List

  • A slice includes the start index and stops before the end index, so [1:4] selects positions 1, 2, and 3.
  • copy() makes a separate shallow list. If the copy becomes [1, 2, 3], appending to it does not change the original list.
  • list.sort() changes the list in place and returns None. Use sorted(nums) when you want a new sorted list.

Shallow and deep copy

  • Shallow copy = new outer container, shared inner objects.
  • Deep copy = new outer container, recursively copied inner objects.
  • Assignment (b = a) = no copy at all.

  • = on b[0] changes what the outer list points to.
  • .append() on b[0] changes the object that the outer list points to.

Deque

collections.deque is a double-ended queue: O(1) adds and removes at both ends. A list is a dynamic array, so it is fast only at the right end.

Declaration

from collections import deque
d = deque()                    # empty
d = deque([1, 2, 3])           # from any iterable
d = deque(range(5), maxlen=3)  # deque([2, 3, 4]): keeps only the last 3

Usage

d = deque([2, 3])
d.append(4)           # deque([2, 3, 4])
d.appendleft(1)       # deque([1, 2, 3, 4])
d.pop()               # 4
d.popleft()           # 1
d.extendleft([1, 0])  # deque([0, 1, 2, 3]): added one at a time, so order reverses
d[0], d[-1]           # (0, 3): peek at both ends
d.rotate(1)           # deque([3, 0, 1, 2])
  • Popping from an empty deque raises IndexError.
  • No slicing (d[1:3] raises TypeError) and no .sort().
  • Use it for queues, BFS, sliding windows and "last N items". Use a list for indexing, slicing and sorting.

Tuple
  • Parentheses alone do not create a tuple; the comma does: (5,).

Dict
  • Keys must be unique. Values may repeat, and modern Python dictionaries preserve insertion order.
  • Iterating (for example, list(d)) a dictionary yields its keys in insertion order.

Functions
  • Default argument values are evaluated when the function is created, not when it's called.
  • Python closures use late binding: variables are looked up when the function is called, not when it is defined.

Exception Handling
  • The else block runs when the try block completes without an exception.

Objects

Remember the inheritance hierarchy:

bool → int → object

Everything in Python ultimately inherits from object, with some nuances around special types.

Classes & self

Definition: self is the first parameter of an instance method. It refers to the object the method was called on. It is a naming convention, not a keyword; any name works, but always use self.

class Counter:
    def __init__(self, start=0):
        self.count = start      # attribute stored on this object

    def inc(self, step=1):
        self.count += step      # reads and updates this object's data
        return self.count

a, b = Counter(), Counter(10)
a.inc()                         # 1
b.inc()                         # 11
Counter.inc(a)                  # 2: what a.inc() really does

Why we write it

  • Python passes the object explicitly. a.inc() is translated to Counter.inc(a), so the method needs a parameter to receive a. Forget it and calling a.inc() raises TypeError: inc() takes 0 positional arguments but 1 was given.
  • One method, many objects. The method is defined once on the class. self tells it which object's data to use, so a and b keep separate counts.
  • Attributes vs local variables. self.count = 0 stores data on the object, and it lasts after the method returns. count = 0 is just a local variable that disappears.
  • No implicit scope. Inside a method you must write self.count or self.other_method(). A bare count raises NameError ("explicit is better than implicit").

Related

  • @classmethod receives the class as cls instead of an instance.
  • @staticmethod receives neither; it is a plain function grouped inside the class.
