Python deque Cheat Sheet

Declaration, usage, time complexity of basic operations, and how it compares to list.

← Back to cheat sheets · Python fundamentals overview

What it is
  • collections.deque ("deck") is a double-ended queue: fast adds and removes at both ends.
  • CPython builds it as a doubly linked list of fixed-size blocks (64 slots each). That is why both ends are O(1) and the middle is O(n).
  • A list is a dynamic array: fast at the right end and for indexing, slow at the left end, because every element must shift.
  • Rule of thumb: queue, BFS, sliding window or "last N items" → deque. Random access, slicing or sorting → list.

Declaration

 
from collections import deque

d = deque()                    # empty
d = deque([1, 2, 3])           # from any iterable
d = deque("abc")               # deque(['a', 'b', 'c'])
d = deque(range(5), maxlen=3)  # deque([2, 3, 4], maxlen=3), keeps the last 3
d.maxlen                       # 3 (None when unbounded)
  • maxlen makes a bounded deque. When it is full, adding on one end silently drops an item from the other end.
  • maxlen is read-only after creation.

Usage

Both ends

d = deque([2, 3])
d.append(4)           # deque([2, 3, 4])        right end
d.appendleft(1)       # deque([1, 2, 3, 4])     left end
d.pop()               # 4                       remove right
d.popleft()           # 1                       remove left
d.extend([5, 6])      # deque([2, 3, 5, 6])
d.extendleft([1, 0])  # deque([0, 1, 2, 3, 5, 6])  note: added one by one, so order reverses
d[0], d[-1]           # (0, 6)   peek at the ends, O(1)

Rotate, search, remove

d = deque([1, 2, 3, 4, 5])
d.rotate(2)           # deque([4, 5, 1, 2, 3])  right by 2
d.rotate(-2)          # deque([1, 2, 3, 4, 5])  left by 2
d.index(3)            # 2
d.count(3)            # 1
d.remove(3)           # removes first 3, ValueError if missing
d.insert(1, 9)        # deque([1, 9, 2, 4, 5])
d.reverse()           # in place
d.clear()

Gotchas

  • pop() / popleft() on an empty deque raise IndexError. Check if d: first.
  • No slicing: d[1:3] raises TypeError. Use itertools.islice(d, 1, 3) or convert with list(d).
  • No sort(). Use sorted(d), which returns a list.
  • Mutating a deque while iterating over it raises RuntimeError.
  • insert() on a full bounded deque raises IndexError instead of dropping an item.
  • Thread-safe for append / popleft from different threads, but use queue.Queue when you need blocking waits.

Common patterns

BFS on a grid or graph

def bfs(graph, start):
    seen = {start}
    q = deque([start])
    order = []
    while q:
        node = q.popleft()          # O(1); list.pop(0) would make BFS O(V^2)
        order.append(node)
        for nxt in graph[node]:
            if nxt not in seen:
                seen.add(nxt)
                q.append(nxt)
    return order

Sliding window maximum (monotonic deque)

def window_max(nums, k):
    q, out = deque(), []            # q holds indices, values decreasing
    for i, x in enumerate(nums):
        while q and nums[q[-1]] <= x:
            q.pop()
        q.append(i)
        if q[0] <= i - k:
            q.popleft()             # front index left the window
        if i >= k - 1:
            out.append(nums[q[0]])
    return out

window_max([1, 3, -1, -3, 5, 3, 6, 7], 3)   # [3, 3, 5, 5, 6, 7]

Last N lines / moving average

last3 = deque(maxlen=3)
for x in [10, 20, 30, 40]:
    last3.append(x)
sum(last3) / len(last3)             # 30.0, from [20, 30, 40]

Palindrome check from both ends

def is_pal(s):
    d = deque(c.lower() for c in s if c.isalnum())
    while len(d) > 1:
        if d.popleft() != d.pop():
            return False
    return True
