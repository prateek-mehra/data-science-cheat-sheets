Ready? Pick a round
  • Each round draws fresh questions from a bank of , spread across core Python: types → strings → lists → tuples & sets → dicts → control flow → functions → comprehensions → scope → classes → iterators → exceptions.
  • Most questions ask what the code prints. Type the output exactly as Python shows it (strings inside a list keep their quotes, a bare print('hi') doesn't). If it prints several lines, type them on one line separated by spaces.

  • A few ask you to write one line of Python instead; the prompt shows >>>.
  • Each question has its own countdown. Press Enter to submit. +1 correct · 0 skip / timeout · −1 wrong
