  1. Q4 — List aliasing:

    Exact question: What does this print?

    x = [1, 2]
y = x
y.append(3)
print(x)

    Options: A) [1, 2]; B) [1, 2, 3]; C) [3]; D) It raises an error.

    Correct result: B) [1, 2, 3]. Assigning y = x makes both names refer to the same list; appending through either name mutates that list.

  2. Q6 — Dictionary keys:

    Exact question: Which statement about Python dictionaries is true?

    Options: A) Keys must be unique; B) Values must be unique; C) Keys must be strings; D) Dictionaries preserve no insertion order in modern Python.

    Correct result: A) Keys must be unique. Values may repeat, and modern Python dictionaries preserve insertion order.

  3. Q9 — List copy:

    Exact question: What does this print?

    a = [1, 2]
b = a.copy()
b.append(3)
print(a, b)

    Options: A) [1, 2, 3] [1, 2, 3]; B) [1, 2] [1, 2, 3]; C) [1, 2] [3]; D) It raises an error.

    Correct result: B) [1, 2] [1, 2, 3]. copy() makes a separate shallow list, so appending to the copy does not change the original list.

  4. Q10 — Mutable default arguments:

    Exact question: What does this print?

    def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item(1))
print(add_item(2))

    Options: A) [1] then [2]; B) [1] then [1, 2]; C) [1, 2] then [1, 2]; D) It raises an error.

    Correct result: B) [1] then [1, 2]. A default list is created once when the function is defined and is reused across calls.

  5. Q12 — dict.get default:

    Exact question: What does this print?

    x = {"a": 1}
print(x.get("b", 0))

    Options: A) None; B) 0; C) KeyError; D) "b".

    Correct result: B) 0. get(key, default) returns the provided default when the key is absent; it does not raise KeyError.

  6. Q13 — One-item tuple:

    Exact question: What does this print?

    print(type((5)))

    Options: A) <class 'tuple'>; B) <class 'int'>; C) <class 'list'>; D) It raises an error.

    Correct result: B) <class 'int'>. Parentheses alone do not create a tuple; the comma does: (5,).

  7. Q14 — Slice boundaries:

    Exact question: What does this print?

    print("python"[1:4])

    Options: A) pyt; B) yth; C) tho; D) ytho.

    Correct result: B) yth. A slice includes the start index and stops before the end index, so [1:4] selects positions 1, 2, and 3.

  8. Q19 — Sorting and joining strings:

    Exact question: What does this print?

    print("".join(sorted(["pear", "apple", "fig"])))

    Options: A) pearapplefig; B) applefigpear; C) ['apple', 'fig', 'pear']; D) An error.

    Correct result: B) applefigpear. sorted() orders strings lexicographically, then join() concatenates them without separators here.

  9. Q20 — Boolean and integer types:

    Exact question: What does this print?

    print(isinstance(True, int))

    Options: A) True; B) False; C) int; D) It raises an error.

    Correct result: A) True. In Python, bool is a subclass of int.

  10. Q21 — Truthiness with or:

    Exact question: What does this print?

    def f(x):
    return x or 10

print(f(0))

    Options: A) 0; B) 10; C) None; D) It raises an error.

    Correct result: B) 10. Since 0 is falsey, 0 or 10 evaluates to the fallback value, 10.

  11. Q22 — Set duplicates:

    Exact question: What does this print?

    print({1, 2, 2, 3})

    Options: A) {1, 2, 2, 3}; B) {1, 2, 3}; C) [1, 2, 3]; D) It raises an error.

    Correct result: B) {1, 2, 3}. A set stores unique values, so repeated elements are removed.

  12. Q24 — Missing substring with find:

    Exact question: What does this print?

    print("hello".find("z"))

    Options: A) None; B) 0; C) -1; D) It raises ValueError.

    Correct result: C) -1. str.find() returns −1 when no match is found; index() would raise ValueError.

  13. Q34 — Exponentiation associativity:

    Exact question: What does this print?

    print(2 ** 3 ** 2)

    Options: A) 64; B) 512; C) 256; D) 36.

    Correct result: B) 512. Exponentiation groups from the right: 2 ** (3 ** 2).

  14. Q43 — capitalize():

    Exact question: What does this print?

    print("cat".capitalize())

    Options: A) Cat; B) CAT; C) cat; D) It raises an error.

    Correct result: A) Cat. capitalize() uppercases the first character and lowercases the remaining characters.

  3. Q10 — Lexicographic string sorting

    Exact question:

    Your answer: A. Correct result: B) ['1', '10', '2'].

  4. Q12 — Exponentiation precedence

    Options: A) -4; B) 4; C) -16; D) SyntaxError.

    Your answer: B) 4. Correct result: A) -4.

    Learned: Exponentiation binds more tightly than unary minus, so this is -(2 ** 2). Use (-2) ** 2 to get positive 4.

  5. Q16 — In-place list sorting

    Your answer: A. Correct result: B) None [1, 2, 3].

    Learned: list.sort() changes the list in place and returns None. Use sorted(nums) when you want a new sorted list.

  6. Q17 — Truthiness of non-empty containers

  8. Q20 — Non-overlapping substring counts

    Options: A) 1; B) 2; C) 3; D) 4.

    Your answer: C) 3. Correct result: B) 2.

    Learned: str.count() counts non-overlapping matches. In aaaa, the matches cover positions 0–1 and 2–3.

  9. Q21 — Shallow list copies with nested lists

    Exact question:

    a = [[1], [2]]
b = a.copy()
b[0].append(9)
print(a)

    Options: A) [[1], [2]]; B) [[1, 9], [2]]; C) [[9], [2]]; D) Error.

    Your answer: A. Correct result: B) [[1, 9], [2]].

    Learned: copy() makes a shallow copy: the outer list is new, but its inner lists are shared. Mutating a shared inner list is visible through both outer lists.

  10. Q22 — Floor division with negative values

    Options: A) -2; B) -3; C) 2; D) -2.3333333333333335.

    Your answer: A) -2. Correct result: B) -3.

    Learned: // floors toward negative infinity. Since −2.333… floors to −3, -7 // 3 is −3.

  11. Q27 — Dictionary iteration order and values

    Exact question:

print(list(d))

    Options: A) ['a', 'b']; B) ['b', 'a']; C) [2, 1]; D) [('b', 2), ('a', 1)].

    Your answer: D. Correct result: B) ['b', 'a'].

    Learned: Iterating a dictionary yields its keys in insertion order. Use d.values() for values or d.items() for key-value pairs.

  1. Q4 — Dictionary key uniqueness:

    Exact question: What does this print?

    d = {"lr": 0.1, "epochs": 5, "lr": 0.01}
print(len(d), d["lr"])

    Answer choices:

    • A. 3 0.1
    • B. 3 0.01
    • C. 2 0.01
    • D. It raises a KeyError

    Your answer: D. Correct result: C, 2 0.01.

    Learned: A dictionary has at most one entry for a given key. A later value for the same key replaces its earlier value; the key contributes only one item to len(d).

  2. Q9 — Comprehension filter order:

    Exact question: What is the value of squares?

    squares = [x * x for x in range(5) if x % 2 == 0]

    Answer choices:

    • A. [0, 1, 4, 9, 16]
    • B. [0, 4, 16]
    • C. [0, 2, 4]
    • D. [4, 16]

    Your answer: A. Correct result: B, [0, 4, 16].

    Learned: The if clause filters the iteration values before the expression is evaluated. Here only 0, 2, and 4 are retained, then squared.
