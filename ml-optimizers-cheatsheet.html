1. Notation you need once

SymbolMeaningRead it as
wtModel parameters at step tWhere we are
gt = ∇w Lt(wt)Gradient of the mini-batch lossLocal uphill direction
ηLearning rateStep scale
β, β₁, β₂Exponential-average decay ratesMemory of previous gradients
εSmall positive stabilizerAvoid division by zero
Unless noted, vectors, squares, divisions, and square roots are element-wise. ḡ is a batch-averaged gradient. Optimizers choose update directions; learning-rate schedules and other training tricks are separate knobs.

2. Difficulty ladder · learn in this order

LevelOptimizer familyNew idea addedQuestion it answers
1 · CoreBatch GD, SGD, mini-batch SGDUse the gradient to step downhill.Which direction lowers the loss?
2 · MemoryMomentum, NesterovAccumulate a smoothed direction; optionally look ahead.Can we reduce zig-zagging and accelerate consistent motion?
3 · AdaptationAdaGrad, RMSProp, AdaDelta, AdamScale each coordinate using gradient history.Can rare or differently scaled features get useful step sizes?
4 · Training detailsAdamW, AMSGrad, AdafactorDecouple decay, constrain moment growth, or compress optimizer state.Can we regularize, stabilize, or save memory?
5 · ScaleLARS, LAMBAdapt step size by layer.Can very large batches train large models reliably?
6 · Modern variantsLion, MuonUse sign-based updates or matrix-aware orthogonalization.Can update structure or optimizer memory be improved?

3. Timeline · formula + what changed

EraOptimizer / updateWhat the new step addsLevel
1951 / 1986Gradient descent / SGD
wt+1 = wt − η gt		Batch GD uses the full data gradient; SGD estimates it from one example or a mini-batch. The core downhill step.1 · Core
1964Momentum
mt = βmt−1 + gt
wt+1 = wt − ηmt		Exponential memory smooths noisy gradients and builds speed in directions that persist.2 · Memory
1983Nesterov / NAG
mt = βmt−1 + ∇L(wt − ηβmt−1)		Compute the gradient at a momentum look-ahead point, so the step can correct before overshooting.2 · Memory
2011AdaGrad
rt = rt−1 + gt²
wt+1 = wt − η gt / (√rt + ε)		Per-parameter rates shrink where gradients repeatedly appear; useful for sparse features. Accumulation can make steps too small over long runs.3 · Adapt
2012RMSProp
vt = ρvt−1 + (1−ρ)gt²
wt+1 = wt − ηgt / (√vt + ε)		Replace AdaGrad’s ever-growing sum with a moving average, so the effective rate does not decay forever.3 · Adapt
2012AdaDelta
E[g²]t = ρE[g²]t−1 + (1−ρ)gt²
Δwt = − RMS[Δw]t−1 / RMS[g]t · gt		Uses running gradient and update magnitudes to reduce dependence on a manually chosen global learning rate.3 · Adapt
2014Adam
mt=β₁mt−1+(1−β₁)gt
vt=β₂vt−1+(1−β₂)gt²
ŵ = w − η m̂t/(√v̂t+ε)		Combines momentum (first moment) with adaptive coordinate scaling (second moment), with bias correction early in training.3 · Adapt
2017AdamW
wt+1 = wt − η[m̂t/(√v̂t+ε) + λwt]		Apply weight decay separately from Adam’s adaptive gradient scaling. This makes decay behave as intended for adaptive optimizers.4 · Details
2018AMSGrad / Adafactor
AMSGrad: v̂t = max(v̂t−1, v̂Adam,t)
Adafactor: factorize row/column second moments		AMSGrad keeps a non-decreasing second-moment maximum. Adafactor approximates Adam’s second-moment state with factored statistics to save memory.4 · Details
2019LARS / LAMB
ut = base optimizer update
w ← w − η · (‖w‖ / ‖u‖) · u		Scale updates by parameter-layer norms. LAMB adds Adam-style moments; designed to make large-batch training practical.5 · Scale
2023Lion
ct = β₁mt−1 + (1−β₁)gt
w ← w − η[sign(ct) + λw]
mt = β₂mt−1 + (1−β₂)gt		Use the sign of a momentum blend for parameter updates; stores one momentum vector and uses less optimizer state than Adam.6 · Modern
2024Muon
Mt = βMt−1 + Gt
W ← W − η · Ortho(Mt)		Apply Newton–Schulz-style orthogonalization to momentum updates for 2D hidden-weight matrices. Specialized; typically paired with another optimizer for embeddings, biases, and normalization parameters.6 · Modern
Dates are first-paper / commonly cited introduction milestones and are approximate for methods that circulated as lecture notes or preprints. They do not imply one optimizer universally replaces the earlier ones.

4. Adam bias correction

  • m̂t = mt / (1 − β₁t)
  • v̂t = vt / (1 − β₂t)
  • At the beginning, moving averages start at zero and are biased low. Divide by the expected accumulated weight to correct this.
  • Common starting values: β₁=0.9, β₂=0.999, ε=10⁻⁸. Tune for the task and implementation.

5. Training optimizations that go along

TechniqueWhat it changes
WarmupRamp the learning rate up at the start to avoid unstable early updates.
LR scheduleDecay or vary η over training (cosine, step, linear, one-cycle); often as important as optimizer choice.
Gradient clippingCap gradient norm: g ← g·min(1, τ/‖g‖); controls extreme steps.
Weight decayRegularize weights; for Adam-like methods prefer decoupled decay (AdamW).
EMAKeep a slow moving average of model weights for smoother evaluation.
Mixed precisionUse lower-precision math to reduce memory and improve throughput; keep sensitive accumulations stable.
AccumulationAccumulate gradients across micro-batches to emulate a larger batch under memory limits.
Reminder: optimizer, learning-rate schedule, batch size, gradient clipping, and regularization interact. Compare them with controlled experiments.
