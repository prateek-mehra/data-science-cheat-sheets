1. Notation & the quick choice

SymbolMeaningTypical use
yGround-truth label or targetWhat should be predicted
pPredicted probability; z is a raw logitClassification
ŷPredicted continuous valueRegression
NNumber of examples or elements being averagedBatch / pixels / tokens
Quick rule: mutually exclusive classes → softmax + CCE; independent binary labels → sigmoid + BCE; continuous targets → regression loss; dense object detection → a weighted sum of classification and box-localization losses. Frameworks often compute BCE/CCE directly from logits for numerical stability.

2. Binary cross-entropy (BCE)

L = −(1/N) Σ [y log p + (1−y) log(1−p)]
  • Use: binary classification or multi-label classification (one independent yes/no target per class).
  • With a logit z, p = σ(z); prefer a numerically stable “with logits” implementation.
  • Common pitfall: do not apply sigmoid twice if the loss already expects logits.
  • For imbalance, consider positive-class weights, sampling, or focal loss; tune calibration separately.

3. Categorical cross-entropy (CCE)

L = −(1/N) Σᵢ Σₖ yᵢₖ log pᵢₖ
  • Use: exactly one correct class from K mutually exclusive classes.
  • p = softmax(z); for one-hot labels this is −log p(correct class).
  • Integer class IDs are commonly accepted by sparse CCE. Use logits-based loss for stability.
  • Distinguish: BCE treats class outputs independently; CCE couples them so probabilities sum to 1.

4. Focal loss · hard examples get more attention

FL(pₜ) = −αₜ (1−pₜ)ᵞ log(pₜ)   where pₜ = p if y=1, else 1−p.
KnobEffectInterview explanation
γ ≥ 0Down-weights easy, already-correct examples as pₜ → 1.Addresses the flood of easy negatives in dense detection.

Use when: extreme foreground/background imbalance, especially dense detection. It is not automatically better for ordinary balanced classification; changing loss can affect calibration.

5. Regression errors

LossFormula (per scalar error e = ŷ−y)Behavior / when useful
MSE / L2(1/N) Σ e²Strongly penalizes large errors; smooth gradients. Sensitive to outliers. Minimizer estimates the conditional mean.
MAE / L1(1/N) Σ |e|More robust to outliers; gradient magnitude is constant away from zero. Minimizer estimates the conditional median.

Smooth L1½e²/β if |e|<β; |e|−½β otherwiseHuber-like loss used in detection and localization; framework conventions differ in the transition scale.
Log-coshmean(log(cosh(e)))Quadratic for small errors and approximately linear for large errors; smooth everywhere.

Interview choice: MSE if large misses should cost disproportionately; MAE if outliers should not dominate; Huber if you want a smooth compromise. Check target scaling and units before interpreting raw loss values.

8. Common interview checks

  • Loss vs metric: loss is optimized; accuracy, F1, AP, or IoU may be monitored but are often non-differentiable.
  • Imbalance: compare class weights, resampling, focal loss, and threshold tuning.
  • Probability: BCE for independent labels; CCE for one-of-K labels.
  • Outliers: square error amplifies them; absolute / Huber-style errors are more robust.
  • Segmentation: pixel CE gives local supervision; Dice/IoU directly emphasize overlap.
  • Multi-task models: Ltotal = Σ λᵢLᵢ; loss scales can dominate, so normalize or tune weights.
  • Numerics: use logits-based cross-entropy and stable log-sum-exp implementations.
