Probability definition

IdeaMeaning
ProbabilityMeasures the fraction of outcomes in a sample space that satisfy some condition.
FormulaP(A) = favorable outcomes / total outcomes

Conditional probability

IdeaFormula
Restrict world to BP(A | B)
Favorable outcomesA ∩ B
New sample spaceB
DefinitionP(A | B) = P(A ∩ B) / P(B), for P(B) > 0
Read as: among cases where B happened, what fraction also have A?

Choosing k things from n

Does order matter?NameNumber of ways
Yes: A-B-C differs from C-B-APermutationP(n, k) = n! / (n - k)!
No: a group is the same in any orderCombinationC(n, k) = n! / (k!(n - k)!)
Example: choose 3 people from 10

Order matters (gold, silver, bronze):
P(10, 3) = 10 * 9 * 8 = 720

Order does not matter (a 3-person team):
C(10, 3) = 10! / (3! * 7!) = 120
Use combinations for a set or team; use permutations for a sequence, ranking, or assignment to distinct roles.

Product rule

FromRearrange
P(A | B) = P(A ∩ B) / P(B)P(A ∩ B) = P(A | B)P(B)
P(B | A) = P(A ∩ B) / P(A)P(A ∩ B) = P(B | A)P(A)
Same intersection, viewed from either condition.

Bayes theorem derivation

Start with the definition:
P(A | B) = P(A ∩ B) / P(B)

Use the product rule on the intersection:
P(A ∩ B) = P(B | A)P(A)

Substitute:
P(A | B) = P(B | A)P(A) / P(B)

So:
P(A | B) = [P(B | A) P(A)] / P(B)
TermIntuitive meaning
P(A | B) posteriorUpdated belief in A after seeing evidence B.
P(A) priorBelief in A before seeing B.
P(B | A) likelihoodHow expected B is if A is true.
P(B) evidenceOverall probability of seeing B.

Bayes with total probability

If A and not-A split all possibilities:
P(B) = P(B | A)P(A) + P(B | not A)P(not A)

Therefore:
P(A | B) =
    P(B | A)P(A)
    -----------------------------------------
    P(B | A)P(A) + P(B | not A)P(not A)
Posterior = likelihood * prior / evidence.

Random variables

IdeaMeaning
Random variableA function that maps each random outcome to a number.
DiscreteCountable values, like die roll, heads in 3 flips, or age in completed years.
ContinuousAny value in an interval, like rainfall, time to finish training, or exact height.
SupportThe possible values the random variable can take.

PMF

IdeaMeaning
PMFProbability mass function: a table or formula giving P(X = x) for each value.
Must sum to 1sum_x P(X = x) = 1
Coin countFor heads in 3 fair flips: 0:1/8, 1:3/8, 2:3/8, 3:1/8
Counts like 1, 3, 3, 1 are not the PMF until divided by total outcomes.

Expectation

For a discrete random variable:
E[X] = sum_x x * P(X = x)

Example:
X takes 1, 2, 3 with probabilities 0.2, 0.5, 0.3
E[X] = 1(0.2) + 2(0.5) + 3(0.3) = 2.1
Expectation is the long-run average, not necessarily the most likely value.

Bernoulli

Question-solving checklist

StepQuick check
1. Read completelyIdentify exactly what is given, what is being asked, and whether order, replacement, or conditioning matters.
2. Build a simple modelSketch a sample space, draw a tree, make a small table, or test a tiny version of the problem.
3. Verify assumptions twiceCheck independence, equal likelihood, replacement, and whether the cases cover every possibility without overlap.
Before calculating, say the model and assumptions out loud. It catches more mistakes than faster arithmetic does.
