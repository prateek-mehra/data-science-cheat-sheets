Mutation vs reassignment

OperationChanges x?Why?
y = xNoBoth reference the same list
y.append(3)YesMutates the shared list
y[0] = 10YesMutates the shared list
y = [4, 5]NoReassigns y to a new list
y = y + [3]NoCreates a new list and reassigns y
y += [3]YesMutates the existing list
