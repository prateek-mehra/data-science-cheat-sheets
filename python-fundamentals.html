Mutation vs reassignment

  • A slice includes the start index and stops before the end index, so [1:4] selects positions 1, 2, and 3.
  • copy() makes a separate shallow list. If the copy becomes [1, 2, 3], appending to it does not change the original list.
  • A default list is created once when the function is defined and is reused across calls.
  • list.sort() changes the list in place and returns None. Use sorted(nums) when you want a new sorted list.

Shallow and deep copy

  • Shallow copy = new outer container, shared inner objects.
  • Deep copy = new outer container, recursively copied inner objects.
  • Assignment (b = a) = no copy at all.
CodeWhat it does
b[0] = [100, 200]Replaces a reference in the outer list
b[0].append(100)Mutates the shared inner list
b.append([5, 6])Adds an element to b's outer list
b[0][0] = 100Mutates the shared inner list's element

Remember this rule:

  • = on b[0] changes what the outer list points to.
  • .append() on b[0] changes the object that the outer list points to.

Dict

  • Keys must be unique. Values may repeat, and modern Python dictionaries preserve insertion order.
  • Iterating (for example, list(d)) a dictionary yields its keys in insertion order.

Strings

  • str.find() returns -1 when no match is found.
  • capitalize() uppercases the first character and lowercases the remaining characters; for example, "cAT".capitalize() returns "Cat".
  • sorted(["10", "2", "1"]) sorts lexicographically.

Tuple

  • Parentheses alone do not create a tuple; the comma does: (5,).

Bool

  • bool is a subclass of int.

Operators

  • == checks whether values are equal.
  • is checks whether two references point to the exact same object.
  • Exponentiation groups from the right: 2 ** (3 ** 2).
  • Empty strings and lists are falsey. or returns the first truthy operand itself, not a Boolean.
  • // floors toward negative infinity.
