Sparse table: static range min/max/gcd

  • Precompute answers for every block length 2^k.
  • Query [l, r] by combining two overlapping blocks of length 2^k.
  • Works in O(1) for idempotent ops: min, max, gcd.
  • Build O(n log n), memory O(n log n). No updates.
# range minimum query on inclusive [l, r]
n = len(a)
K = n.bit_length()
st = [a[:]]
for k in range(1, K):
    half = 1 << (k - 1)
    prev = st[-1]
    st.append([
        min(prev[i], prev[i + half])
        for i in range(n - (1 << k) + 1)
    ])

def query(l, r):
    k = (r - l + 1).bit_length() - 1
    return min(st[k][l], st[k][r - (1 << k) + 1])

Syntax traps worth memorizing

  • for i, x in enumerate(a): gives index and value.
  • for i in range(len(a)): gives index only.
  • a[-1] is last item. Empty list raises error.
  • sorted(a) returns new list. a.sort() returns None.
  • is checks identity. Use == for value equality.
  • nonlocal ans inside nested DFS if assigning outer variable.
  • sys.setrecursionlimit(10**6) can help deep DFS, but iterative is safer.
  • dict.values() and dict.keys() are views, wrap with list() if needed.
  • heapq compares tuple elements left to right.
  • copy = a[:] shallow-copies a list.
