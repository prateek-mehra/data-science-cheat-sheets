Before you start

  1. The timer starts when you press Start test and cannot be paused. Refreshing the page or closing the tab does not stop it.
  2. You work in a Python notebook. The data files are in the working directory; read them with pd.read_csv("train.csv").
  3. Task answers are read from the variables in the running kernel when you submit. If you restart the kernel, re-run your cells.
  4. Predictions go in submission.csv — write it from the notebook or upload it in the Files tab.
  5. When time runs out, your notebook is submitted automatically as it stands.
  6. Keys: Shift+Enter run and move on · Ctrl/⌘+Enter run in place · Tab autocomplete · Esc then A/B add cell above/below, D D delete, M/Y markdown/code.
