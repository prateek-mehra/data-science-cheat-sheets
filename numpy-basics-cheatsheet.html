CodeSelects

5. Math & broadcasting

CodeMeaning

Broadcasting: compare shapes from the right; dimensions are compatible when equal or one of them is 1.

6. Aggregate (axis matters)

CodeResult

a.min(), a.max()Extremes
a.sum(axis=0)Down the rows - one value per column
a.sum(axis=1)Across columns - one value per row

9. Gotchas

  • Slices share memory: b = a[1:3]; b[0] = 99 changes a. Use a[1:3].copy() when you need independence.
  • Python list * 3 repeats the list; NumPy array * 3 multiplies every element.
  • a * b is element-wise; matrix multiplication is a @ b.
  • An int array stays int: assigning 3.9 into it stores 3. Convert with astype first.
  • reshape must preserve the element count - a wrong target shape raises, it never silently pads.
